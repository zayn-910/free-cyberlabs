# Hint 2

Open this hint only after using Hint 1.

A chart reference is URL-safe Base64 for text such as `WC-1012`. Decode one of your own references, then form the reference for chart `WC-1001`. The chart page itself will refuse it — that refusal is expected. Instead, open your own printable summary, keep the same address shape, swap in the reference for `WC-1001`, and read the systems note on the chart that opens.
